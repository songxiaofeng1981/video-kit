# “宋的财经模板”使用说明

## 怎么调用

在 Claude Code 或 Codex 中直接说“使用宋的财经模板”，或显式写 `$song-finance-video-template`。

最稳的描述包含四项：目标项目、出现时间、效果名称、要替换的内容。

```text
使用 $song-finance-video-template 修改当前 Remotion 视频。
在 00:42 加入“财经重点词·三级递进”：
第一行：市场真正担心的
第二行：不是销量
核心词：是利润率
底部说明：关注盈利质量，而不只是收入增速

保持模板原动画和颜色，只替换文案。
先打开 Remotion Studio 预览，不要渲染。
```

## 让 AI 自动挑效果

```text
使用 $song-finance-video-template 阅读这段口播稿，给现有视频挑选合适的模板效果。
只使用模板里的五种组件，保持克制，不要重新设计。
先列出“时间点—口播句—效果—内容”的安排，再加入项目并打开 Studio。
不要最终渲染。
```

## 调整已经插入的效果

```text
使用 $song-finance-video-template 调整 00:42 的“财经重点词·三级递进”。
动画节奏、位置和配色保持不变，只把核心词改成“自由现金流”，底部说明删除。
打开 Studio 停在这一段，不要渲染。
```

## 常用效果名称

- 新闻截图弹出
- 数据卡
- 图表展示
- 财经重点词·三级递进
- 图片/截图全屏切换

## 描述不完整时会怎样

- 没说时间：AI 根据口播语义选择位置，但应先告诉你选择结果。
- 没说效果：AI 按 `effects-catalog.md` 选择最匹配的一种。
- 没说是否渲染：默认只打开 Studio，不生成 MP4。
- 文案太长：优先换行或小幅缩小字号，不改母版动作。

## 想改模板本身

明确说明“修改母版并影响以后所有视频”。否则 AI 应只修改当前项目传入的参数，不动 Skill 内的组件。

示例：

```text
修改“宋的财经模板”的母版：以后所有“财经重点词·三级递进”的核心词都改为白色，红线改为金色。先在效果 Demo 中验证，不要直接修改正式视频。
```
