以后怎么用？

新开一个会话（Claude Code 或 Codex），
说这一句就够了。
用洞察视频模板，把这个 HTML 做成视频。主角：XX；原因：A、B；BGM：xxx.mp3。不要渲染。
HTML
拖进对话，或给出文件路径
主角
最重要的那一个数字
原因
最直接的两个，其余它自己压缩
BGM
可以不给；给了自动调好音量
做完后打开它给的预览地址（一般是 http://localhost:3000/…）看效果，不满意直接说哪里要改。
03 / 06

它会做什么？

每次都按同一个流程，
不会自由发挥。
  1. ① 先整理 HTML不适合就直说，配色照原文
  2. ② 建项目、填内容依赖共用，只改一份内容文件
  3. ③ 调 BGM 音量统一到 -16 LUFS 左右
  4. ④ 截图自检文字溢出就缩短文字
  5. ⑤ 打开预览默认不导出成片
要导出 MP4，得明确说“渲染”或“导出成片”。
04 / 06

做了什么？

① 一个技能：把套路写死。
一个主角 + 两个原因 + 其余压缩；每页时长、每段字数上限。新视频只改内容文件，不碰动画代码——不走样，也省 token。
② 一个模板：固定四种页面。
封面4 秒标题、钩子、引导
主角数字页5 秒大数字倒数、震一下、盖章、公式拆解
原因聚焦页6 秒两个原因依次亮起，带钱流动画
结论页4 秒最多 3 条结论 / 验证锚点
想要新样式要改组件，会影响以后所有视频——AI 会先问你要不要写回模板。
